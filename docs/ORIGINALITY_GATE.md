# Originality Gate

Originality gate adalah heuristic product assessment, bukan keputusan hukum.
Pemeriksaan mencakup sudut baru, hook, komentar substantif, kesimpulan,
voice-over, fungsi editorial cuplikan, rasio kontribusi, dominasi sumber,
durasi sumber tanpa interupsi, dan kemiripan komentar terdahulu.

Status:

- `ready_for_manual_review`
- `revision_recommended`
- `transformation_required`

Status `transformation_required` memblokir render final tetapi tidak memblokir
preview. Semua hasil tetap memerlukan tinjauan manusia. Angka konfigurasi bukan
aturan hukum dan tidak menjamin monetisasi atau kepatuhan platform.
